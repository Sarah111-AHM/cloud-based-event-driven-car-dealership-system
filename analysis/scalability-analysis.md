# Scalability

This section evaluates how the **cloud-based, event-driven system** scales with more branches and users.

- The system can support **multiple branches** and **many users** simultaneously.  
- Cloud storage ensures that all branches access the same data without conflicts.  
- Event-driven design allows adding **new features or services** without changing the main system.  

**Example:**  
Adding 5 more dealerships is simple because each branch connects to the central cloud database, and all events are processed the same way.
