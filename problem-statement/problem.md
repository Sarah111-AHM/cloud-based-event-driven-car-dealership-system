# Problem Statement

Traditional car dealership systems have several challenges:

- **Slow Updates:** Sales, inventory, and customer records are often updated manually, which causes delays.  
- **Limited Scalability:** Adding more branches or users is difficult with old systems.  
- **High Costs:** Maintaining servers, software, and staff for manual operations is expensive.  
- **Poor Real-Time Handling:** Events like a car sale or inventory change are not reflected immediately.  

This project proposes a **cloud-based, event-driven system** to solve these problems. The system will:

1. Store all data in the cloud, accessible by all branches.  
2. Automatically update records when events happen (e.g., car sale, new stock).  
3. Reduce manual work and operational costs.  
4. Improve performance and support multiple branches and users in real-time.  

By addressing these issues, the system becomes **faster, scalable, and more efficient** than traditional dealership software. This problem statement will guide the system design, analysis, and evaluation in the next sections.
