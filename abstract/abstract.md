# Abstract

**Title:** Design and Analysis of a Cloud-Based Event-Driven Management System for Car Dealerships

This project studies a cloud-based, event-driven system for car dealerships. Traditional dealership systems have many problems, such as slow updates, manual work, limited scalability, and high costs.

The goal of this project is to use **cloud computing** and **event-driven design** to make a system that is faster, flexible, and works in real-time. All data is stored in the cloud, and important actions like car sales, inventory updates, and customer management happen automatically through events.

Main points of this study:

1. **System Design:** A cloud system that can grow and work for many dealership branches.  
2. **Event-Driven Workflows:** Using small services that start when events happen, like a sale or inventory change.  
3. **Performance Analysis:** Checking how the system works under heavy use.  
4. **Cost Comparison:** Looking at costs of cloud-based vs traditional systems.  

This project uses a research-style method like papers in **Google Scholar**, with clear design, analysis, and documentation.

**Keywords:** Cloud Computing, Event-Driven Design, Car Dealership, System Analysis, Performance, Scalability.
